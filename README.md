# 🎓 Student Grade Calculator

A simple Python-based Student Grade Calculator that calculates total marks, percentage, grade, and pass/fail status based on the marks entered by the user.

## 📌 Project Description

The Student Grade Calculator is a beginner-friendly Python project designed to demonstrate basic programming concepts.

The program accepts marks for five subjects and automatically calculates:

- Total marks
- Percentage
- Grade
- Pass/Fail status

## 🛠️ Technologies Used

- Python
- Python Lists
- Loops
- Functions
- Conditional Statements
- Exception Handling

## ✨ Features

- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Handles invalid input
- Calculates total marks
- Calculates percentage
- Assigns grades automatically
- Checks whether the student has passed or failed
- Displays a clean result report
